# C++ 语言基础与类和对象笔记

## 一、 NULL 与 nullptr

C++中 `NULL` 被宏定义成了整型 `0`，C 语言中为 `(void*)0`。

而且在 C 语言中 `void*` 类型指针可以隐式类型转换成任何类型指针，不需要强转，但是 C++ 不允许：

```cpp
// C++
void* p1 = NULL;
int* p2 = p1; // 此时如果 p1 不强转则会报错，需要 int* p2 = (int*)p1;

// C（不严格）
void* p1 = NULL;
int* p2 = p1;
```

C 语言中 `NULL` 既可以转换成任意类型，也可以转换成整型 `0`。

所以有了空指针 `nullptr` 的产生，它可以转换成任意类型的指针类型，与 C 中的隐式类型转换相比，它只能被转换成指针，而不能转换成整型。

## 二、 类与 struct

定义类时，既可以使用 `class` 也可以使用 `struct`，只不过不需要 `typedef` 重命名，类名就是变量名，而且用 `class` 定义的类默认属性及函数都是 `private`，而 `struct` 默认是 `public`。

访问限定符限定的是类外是否能进行访问，在类内可以随便访问。

---

## 三、 对象大小与内存对齐

类内的函数不会存在对象中（存在公共区域），但是成员变量会存。

**为什么会内存对齐？**
从内存中读取数据时，并不是从任意位置开始读取，而是从整数倍位开始读取。

没有成员变量的类的内存大小是 `1`，这里的 `1` 纯粹是为了占位标识对象存在。

---

## 四、 this 指针

同一个类中定义出的不同对象的成员函数是同一个，不会存储多份，那么在调用函数时，它是如何获取不同对象中的不同成员变量呢？

`this` 指针解决了这一问题，`this` 指针不能写在实参和形参中，但是可以在函数定义内显式使用，但是不写也会自动加上 `this` 指针访问（`this` 指针存在栈中）。VS 中会优化将 `this` 指针放入了寄存器中。

`Class* const this`

## 五、 类的默认成员函数

### 1. 构造函数 （初始化对象，并非创造对象）
* 无参构造函数在创建对象时无需括号（防止分不清对象实例化还是函数声明），有参构造函数需给出括号给定参数。
* 防止忘记手动初始化产生垃圾值。
* 全缺省构造函数能完美包含无参和带参构造函数的优点。

**默认构造：**
* 无参构造函数
* 全缺省构造函数
* 不写构造函数编译器默认生成的构造函数
