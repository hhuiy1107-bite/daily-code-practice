# C++ 引用与输出型参数学习笔记

## 一、 输出型参数 (Output Parameters)
- **概念与背景**：由于 C/C++ 函数只能有一个返回值，当需要让函数“返回”多个值时，可以通过外界传入指针/引用的方式来实现。
- **工作机制**：外界将变量的地址（指针）传入函数，函数内部通过**解引用**修改该地址对应的内存数值，从而将结果带回给外界调用方。

---

## 二、 引用 (Reference)

### 1. 自动与基本特性
1. **必须初始化**：引用在定义时必须进行初始化（即必须指定它是谁的别名），不存在空引用。
2. **多重引用**：一个变量可以有多个引用（即同一个变量可以有多个别名）。
3. **不可变更指向**：引用“一旦绑定，终身不能改变指向”。试图给引用重新赋值时，本质上是**对原变量进行赋值操作**，导致原变量的值被改变，而不是改变引用的绑定对象。
4. **不额外开辟空间**：从语法概念层面上，引用是变量的别名，不占用独立的内存空间（与原变量共享同一块内存地址）。
