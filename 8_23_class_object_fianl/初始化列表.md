# C++ 构造函数、初始化列表与隐式类型转换核心机制

## 1. 隐式类型转换与临时对象

* **底层机制**：在使用单参数或多参数花括号列表进行赋值式实例化时，编译器会先利用给出的实参**构造一个临时对象**，然后再通过**移动构造或拷贝构造**将临时对象转移给正在实例化的对象（在现代编译器优化下，该步骤常被直接合二为一完成构造）。
* **支持情况**：
  * **单参数构造函数**：原生支持隐式类型转换，例如 `Data d1 = 2026;`。
  * **多参数构造函数**：在 **C++11** 标准起支持使用多参数列表初始化完成隐式转换，例如 `Data d2 = {2026, 8, 23};`。
* **引用与权限管理**：
  * 隐式类型转换生成的临时对象具有**常性（右值 / 常量属性）**。
  * 如果函数形参或局部变量使用普通非 const 引用接收临时对象，会导致**权限放大**而引发编译报错。
  * **设计准则**：在不修改实参内容的情况下，引用形参应尽量加上 `const`（如 `const Data& d`），既能避免不必要的拷贝开销，又能安全兼容隐式类型转换产生的临时对象。

## 2. 初始化列表与构造函数体的区别

* **本质划分**：
  * **初始化列表**：是类中所有成员变量**唯一真正被定义和分配内存初始化的时机**，每个成员在初始化列表中**只能且必须出现一次**。
  * **构造函数体内部（`{}`）**：此时所有成员变量已经定义完毕，花括号内的赋值语句本质上是**二次赋值（覆盖）**，同一成员可以在函数体内被重复赋值多次。
* **必须在初始化列表中初始化的 4 种情况**：
  * `const` 修饰的成员变量（定义时必须初始化，无法在函数体内二次赋值）。
  * **引用类型成员变量**（必须在定义时绑定实体对象，不可后续重绑定）。
  * **没有默认构造函数的自定义类型成员**（编译器无法自动无参构造，必须在列表显式调用带参构造）。
  * **没有默认构造函数的基类（父类）**（派生类必须在列表显式调用基类带参构造）。

---

## 3. 自定义类型成员的初始化规则

* **存在默认构造函数**：
  * 若当前类的初始化列表中**未显式写出**该成员，编译器会自动调用其自身的默认构造函数（通过它自己的初始化列表完成初始化）。
  * 也可以在当前类的初始化列表中**显式调用**它的其他构造函数，从而覆盖默认行为。
* **不存在默认构造函数**：
  * 编译器无法自动完成无参构造，**必须**在当前类的初始化列表中显式提供其实例化所需的参数。

## 4. C++11 缺省值与初始化列表的协同逻辑

无论是否手动编写初始化列表，所有成员变量**必然会走初始化列表阶段**完成定义。其具体取值优先级如下：

1. **显式写在初始化列表**：直接采用初始化列表中指定的实参、常量或表达式进行初始化。
2. **未显式写在初始化列表**：
   * **声明处提供了缺省值**：自动采用声明处的缺省值进行初始化。
   * **声明处未提供缺省值**：
     * **内置类型**：取值不确定，大概率保留栈区/堆区的随机垃圾值（取决于编译器实现与构建模式）。
     * **自定义类型**：自动调用其无参默认构造函数；若该类型没有默认构造函数，则直接触发编译报错。

隐式类型转换实例化对象时，给出的参数先构造一个临时对象，然后在拷贝给正在实例化的对象

引用如果不改变尽量都加const，因为可能为了便捷使用隐式类型转换，但是隐式类型转换具有常性，需要同样的权限

单参数才支持隐式类型转换的构造函数ru(Data d1 = 3);但是c++11中多参数也支持（Data d2 = {2026, 8, 23 } ）

普通构造函数中成员变量可以多次初始化，但是初始化列表时只能出现一次	 
必须使用初始化列表的情况：const修饰的成员变量、引用变量（在定义时绑定被引用对象）、没有默认构造函数的自定义类型


成员变量定义的时候是在初始化列表时发生，const类型变量只能在定义的地方初始化，所以需要初始化列表，在构造函数内无法初始化，会造成权限放大
也用也是如此，在定义的地方进行初始化

初始化列表是所有成员变量唯一真正被定义和初始化的时机，成员变量中如果有自定义类型成员，在初始化列表时，这个自定义类型成员是不是需要调用自己的默认构造函数中的初始化列表给自己定义和初始化，如果没有默认构造函数（如定义了构造函数但是未传参），那么是就需要在我们自己显式定义的初始化列表中写一个，当然就算有自己的默认构造函数，也可以在我们的初始化列表中写一个，从而调用我们自己的

C++11中可以在成员变量声明时给出缺省值，给初始化列表使用，不传入参数时使用缺省值（默认值）

即使没有对成员变量进行初始化，但是也会进入初始化列表，因为成员变量在初始化列表处定义

对于初始化列表中显式写出成员直接采用传入值，如果没有显式写出就采用缺省值，初始化列表也可以像构造函数一样写无参的，则直接调用缺省值，如果没有缺省值就报错
