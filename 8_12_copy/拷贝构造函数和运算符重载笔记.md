# C++ 核心知识点整理

## 一、 内存与拷贝机制
* `memcpy` 不会处理内存重叠的问题，此时需要用 `memmove`
* 浅拷贝就是完全的拷贝，指针指向的一块地址都会拷贝过去，使得拷贝值也指向这个空间
* 拷贝构造函数是构造函数的一个重载
* **小技巧**：如果显式实现析构函数，那么就必须显式实现拷贝构造函数，因为有资源的申请，不能指向同一块空间

---

## 二、 函数返回值与引用传参
* “传值返回如果类型为类，那么在局部对象销毁之前，会先以它为模板实例化出一个新临时对象（调用拷贝构造函数），之后局部对象才被销毁，这个新对象会被带回 main 函数交给接收变量。”
* 如果传引用返回那么就相当于野引用，因为局部变量已经销毁，传出去的值不可预测
* 传引用返回本质是为了减少拷贝，但是一定要确保返回对象在当前函数结束以后还存在，而不是局部变量
* 拷贝构造函数内部如果是传值传参，那么调用拷贝构造函数会造成死循环

---

## 三、 函数指针与成员函数指针
* 普通函数的函数名就是函数指针，但是在 C++ 中成员函数必须指定类域并且给取地址符号 `&`
* 拿指针回调成员函数时，解引用成员函数必须 `.*` 解引用（因为隐式传递了 `this` 指针在）所以先 `.` 找到再解引
* 注意函数指针的命名标准：`int (*)(int, int)`

---

## 四、 运算符重载与赋值重载
* 运算符重载中的成员至少要有一个类类型
* 两个运算符重载函数也可以构成函数重载
* 赋值运算符重载也属于默认成员函数
* **赋值重载拷贝**：用于两个已经存在的对象
* **拷贝构造**：用于一个已经存在的对象，另一个正在创建为其初始化

```cpp
Data d1(2026);
Data d2(2026);

// 赋值重载拷贝
d1 = d2;

// 拷贝构造
Data d3(d1);
Data d4 = d1;
两个运算符重载函数也可以构成函数重载

赋值运算符重载  也属于默认成员函数
赋值重载拷贝：用于两个已经存在的对象
拷贝构造：用于一个已经存在的对象，另一个正在创建为其初始化
Data d1(2026);
Data d2(2026);
//赋值重载拷贝
d1 = d2;

//拷贝构造
Data d3(d1);

赋值支持连续赋值

赋值运算符重载有返回值就是为了连续的赋值，并且因为传值返回为类类型，所以建议传引用返回，可以减少拷贝次数

赋值重载函数传参的时候需要还是按照的运算符重载的规定，在类内定义时需要少传入一个参数


C++中，在类内定义的成员函数默认为内联函数
内联函数不能声明定义分离，因为看到声明会直接展开，可是这时候还不能找到定义
