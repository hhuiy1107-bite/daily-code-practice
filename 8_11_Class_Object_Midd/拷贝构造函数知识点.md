# C++ 拷贝构造函数核心机制总结

## 1. 拷贝构造函数的定义
拷贝构造函数就是用一个已经实例化出来的对象来初始化另一个对象。

## 2. 函数传值传参触发拷贝构造
对于如下代码：

```cpp
void Func1(Date d)
{
    ;   
}

Date d1;
Func1(d1);
```

在这里 `Func1` 中的形参 `d` 相当于创建的第二个对象。因为执行 `Func1(d1)` 时，需要用 `d1` 去初始化形参中的 `d`。这完全符合“用一个对象 (`d1`) 去初始化另一个对象 (`d`)”的定义，所以它必然会触发拷贝构造函数！

## 3. 拷贝构造函数的参数要求
拷贝构造的第一个参数必须是类类型对象的引用，并且其他额外的参数都需要有默认值，即需缺省值。

## 4. 传值传参导致无限递归（为什么必须使用引用）
想用对象去初始化对象时，如果传值传参，那么会先对拷贝构造函数中的形参进行拷贝从而再次调用拷贝构造函数，然而再次调用拷贝构造函数还会传值传参继续调用拷贝构造函数（每次触发拷贝构造函数都会传参形成新的拷贝构造函数进而再次传参）。所以需要利用 `&` 使形参直接访问原对象，不再进行拷贝。

## 5. 成员变量的访问权限
因为拷贝构造函数在类内，所以可以直接访问成员变量进行初始化。

## 6. C++ 标准语法规定
C++规定自定义类型对象在传参拷贝时必须调用拷贝构造。

## 7. 编译器默认生成的拷贝构造函数规则
如果不显式定义拷贝构造函数，那么编译器会自动生成拷贝构造函数：
* **内置类型**：完成值拷贝或者浅拷贝（一个字节一个字节拷贝）。*注意：默认构造函数和析构函数不会对内置类型处理。*
* **自定义类型**：会调用它的拷贝构造（与构造函数和析构函数一致）。
