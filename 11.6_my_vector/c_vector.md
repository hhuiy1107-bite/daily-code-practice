# C++ 知识点与 vector 模拟实现总结

### 1. 模板与 typename
在模板中，通过 `::` 从类中取东西时，如果类是一个未实例化的模板，那么编译器默认会当成变量，因此必须加 `typename` 声明它是类型；如果类已经实例化，那么取出来既可以是类型也可以是变量。

---

### 2. 数组与指针边界问题
数组类问题在通过下标解决问题时，需要注意下标为 0 时的问题；但是如果通过指针解决问题就无需在意 pos 为 0 的问题，但是指针会存在越界问题，注意边界。

---

### 3. 迭代器失效
容器 `erase` 后迭代器会失效，`insert` 看情况（是否扩容）。

---

### 4. 内置类型的伪构造函数
从语法表现和概念抽象上来说内置类型也存在伪构造函数：
* `int a = int();` // 值初始化（Value Initialization），a 被置为 0
* `int b = int(10);` // 直接初始化，b 赋值为 10

---

### 5. vector 的初始化与 resize
`resize` 的功能是用来初始化值，我们可以在实例化 `vector` 时直接初始化：
* `vector<int> v = {1, 2, 3, 4, 5};`
* 也可以利用 `resize` 来初始化，例如：
  ```cpp
  vector<int> v;
  v.resize(10, 1);
  ```

---

### 6. 构造函数规则与 default
构造函数规则：
* 不写任何构造函数，编译器会自动生成默认构造函数。
* 但是如果写了**拷贝构造函数或任何带参构造函数**（注：只写赋值运算符重载 `operator=` 并不会阻断编译器自动生成默认构造），这时再想使用默认无参构造函数则无法自动生成。在 C++11 中可以利用关键字 `default` 强制生成：
  ```cpp
  vector() = default;
  ```
* 例如：我们在最开始直接给成员变量缺省值，默认生成的构造函数能够使用缺省值完成构造，因为没有内存的申请，所以默认生成的足够使用；但是后来如果我们显式定义了拷贝构造函数或其他构造函数，再想通过编译器自动生成的默认构造函数去使用缺省值是不行的，必须显式补上 `vector() = default;`。

### 8. vector 模拟实现中 `const_iterator& begin() const` 出错原因分析

#### 问题代码
```cpp
const_iterator& begin() const
{
    return _start;
}
```

#### 原理解析与修正
此处出错并非“篡改了原被绑定者”，而是触碰了 C++ 的引用绑定规则：
1. **隐式类型转换**：`_start` 的类型是 `T*`，而返回类型是 `const_iterator&`（即 `(const T*)&`）。从普通指针转换为常量指针时，编译器会在临时存储区（寄存器或栈）生成一个临时的 `const T*` 右值。
2. **非法引用绑定**：在 C++ 中，**非常量左值引用严禁绑定临时对象（右值）**，因此在编译期就会直接报错。
3. **正确做法**：迭代器底层是指针（大小仅为 4/8 字节），**直接传值返回**即可，不能也不需要返回引用：
   ```cpp
   const_iterator begin() const
   {
       return _start;
   }
   ```
